The Mac app AULA never made.

Lighting, per-key colour, the keyboard's clock and presets for the AULA S98 Pro. One small native app, with no virtual machine.

Download for macOS View on GitHub

Apple silicon · macOS 13 or newer · USB cable

This is the app's real preview running in your browser. Click or drag across the keys to paint them. The effects here are a demo; the keyboard's own firmware draws the real ones.

Everything you'd boot Windows for.

AULA's software is Windows-only. This talks to the keyboard directly over USB, and it doesn't need an account or the network.

20 lighting modes

Pick an effect, then set its colour, brightness, speed and direction.

Per-key painting

Click or drag across all 96 keys, with undo, fill, rainbow and gradients.

Keyboard clock

Fixes the date on the keyboard's screen and keeps it in sync.

Presets

Save, import and export effects and per-key layouts.

Per-app lighting

Bind a preset to an app, and the lighting follows you as you switch.

Colour calibration

Teach the app how your LEDs really look, so the screen matches the keys.

Menu-bar quick controls

Change the lighting in one click, or open the full editor.

Command line

A 36 KB tool for your scripts and shortcuts.

Tiny and private

About 6.5 MB, with no telemetry and no background suite.

Install in a minute.

This free project isn't notarized by Apple, so macOS asks you to approve it once.

Download

  1. Download the zip, unzip it, and drag the app to Applications.
  2. Open it. macOS will refuse the first time.
  3. In System Settings › Privacy & Security, choose Open Anyway.

Or build it yourself

git clone https://github.com/Lawsinex/aula-s98-pro-companion-macos.git
cd aula-s98-pro-companion-macos
python3 -m pip install numpy pillow
./scripts/install.sh
